# Dictionary App

A dictionary app that lets users search for any word and get its 
definition, pronunciation, and related images.

🔗 **Live demo:** https://ld-dictionary.netlify.app/

<img width="933" height="565" alt="screenshot" src="https://github.com/user-attachments/assets/3a712bc9-8dc2-4e37-adb6-4db0dd4760ea" />

## What it does

User types in a word and gets back its definition, related images, phonetics and examples.
The app pulls dictionary data from the SheCodes API and images from the Pexels API.

## Built with

- HTML
- CSS
- JavaScript
- React
- SheCodes API
- Pexels API

## What I learned / would improve

This project was my first time combining two different APIs in one app. 
If I revisited it, I'd handle words without results better.

## Run it locally

```bash
git clone https://github.com/delialo/dictionary-project.git
cd dictionary-project
npm install
npm start
```
